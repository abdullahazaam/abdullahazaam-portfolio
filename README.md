# Abdullah Azaam — Developer Portfolio

Modern cinematic developer portfolio built with React, TypeScript,
Three.js and GSAP.

[Live Portfolio](https://abdullahazaam-portfolio.vercel.app/)

## Preview
<img width="1366" height="603" alt="image" src="https://github.com/user-attachments/assets/fb90644f-12c7-403f-bbd1-b89e79b1dd9e" />


## Features
- Cinematic red/black UI
- Interactive 3D skill cards
- Animated project cards
- Scroll-based animations
- Responsive design
- Smooth scrolling
- Project showcase
- Contact section

## Tech Stack
React
TypeScript
Vite
Three.js
React Three Fiber
GSAP
Framer Motion
Lenis
Tailwind CSS

## Run Locally

npm install
npm run dev

## Production Build

npm run build
