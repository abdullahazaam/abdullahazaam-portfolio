## About This Portfolio

This portfolio is an interactive digital showcase built to present my work as a full-stack developer. It bridges robust backend engineering across **C#, ASP.NET Core, SQL Server, PHP, and Laravel** with creative, fluid frontend web technologies including **React, TypeScript, Three.js, and GSAP**. The application is structured with unified viewport sections, cinematic dark aesthetics, and lightweight micro-interactions designed for seamless performance across all devices.

---

## Key Features

- **Cinematic Atmosphere**: Dark obsidian surfaces with subtle crimson ambient glows, layered glassmorphism, and responsive perimeter lighting.
- **Interactive 3D & Micro-Interactions**: Custom card tilt dynamics, orbital geometry animations, and cursor-follow radial glow.
- **Scroll-Driven Motion**: Coordinated scroll trajectories and timeline tracking driven by GSAP ScrollTrigger and Lenis smooth scrolling.
- **Unified Section Geometry**: Calibrated section heights delivering an edge-to-edge cinematic presentation on desktop and mobile.
- **Accessibility & Performance**: Optimized asset delivery with native support for `prefers-reduced-motion` and responsive viewport breakpoints.

## Getting Started

### Installation & Development

Clone the repository and start the local development server:

```bash
git clone https://github.com/abdullahazaam/abdullahazaam-portfolio.git
cd abdullahazaam-portfolio

npm install
npm run dev
```

### Production Build

Compile TypeScript and bundle optimized assets for production:

```bash
npm run build
```

To test the generated production build locally:

```bash
npm run preview
```
